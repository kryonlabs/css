# Changelog

## Unreleased

- `transform`, `transform-origin`, `scale` and `rotate` are known browser-only declarations: a shared sheet keeps them for the DOM export and a plain native parse refuses them with the reason, instead of failing on an unknown property.

- `linear-gradient()` takes any angle (`deg`, `turn`, `rad`, `grad`) or `to` a side or corner, and two to six color stops with `%` positions, in `background` and `background-image`; Row, Column and Grid paint them, other widgets a top-to-bottom gradient of the first and last colors (`css_tool check` says so). Radial, conic and repeating gradients are refused natively with the reason. The pack format is 101 words a rule. Pins Kryon d0711324.

- Selectors take tree context natively: one ancestor by class or id (`.card Text`), the parent (`.card > Text`), `:first-child`, and `:not(.class)` or `:not(:state)`, also in nested `&` rules, and the DOM export writes them as browser selectors. `:last-child`, `:nth-child()`, typed or second ancestors and sibling combinators fail with the native idiom. The pack format is 87 words a rule. Pins Kryon 56777c65.

- Per-side borders are native on Row, Column and Grid: `border-top|right|bottom|left`, `border-block-start|end` and `border-inline-start|end`, each with `-width`, `-color` and `-style`, with `var()` values; a uniform border later in the same rule clears earlier sides. With a border radius the box paints its uniform border and `css_tool check` reports it. `outline`, `outline-width` (also `thin`, `medium`, `thick`) and `outline-offset` size the native focus ring; `outline: none` keeps it, and `css_tool check` says so. Border widths take `thin`, `medium` and `thick`. The pack format is 82 words a rule. Pins Kryon d97c19e8.

- Percentages are native in `width`, `height`, `min-width`, `max-width`, `max-height` and the logical aliases on Row, Column and Grid, in `min-height` on those containers, and in `flex-basis` (also through `flex`): the parser keeps the percentage with a `percent` mask and Kryon layout resolves it against the parent's content box. A percentage inside `calc()`, `min()`, `max()` or `clamp()`, or on another widget's size, fails a plain native parse with the reason. The pack format gains the three masks (72 words a rule); older packs are refused as stale. Pins Kryon 60f081a4.

- The README property table is generated by `css_tool properties` from the parser catalog (src/parser/catalog.zi); `make check` fails when it is stale, and the tests parse every row natively on its target.

- A plain `CssSheetParse` refuses browser-only declarations instead of skipping them silently; `CssSheetParseWithDiagnostics` reports them. The browser-only declaration counters are gone, and packs refuse such declarations through the same parse.

- `box-shadow` maps to Kryon elevation roles, the `font` shorthand sets size, line height, weight and style, and generic font families map to the theme face or the code font role.

- Rules nest `&:state`, `&.class`, `&#id` and `&[attribute]` rules one level deep, flattened into compound selectors and exported with the parent selector. Combinator, `:not()` and child-position errors name the native idiom.

- Lengths take em, vw and vh and calc(), min(), max() and clamp(): static ones fold while the sheet is read, viewport ones resolve at install and packs keep them; CssSheetSameMedia reports a change when a new viewport changes an active length. var() fallbacks may nest one var(), and var(--kryon-NAME) reads the installed theme palette.

- Lower margin, min/max width, max height, overflow and text-align to native box styles. Packs use one rule layout; a pack in an older layout is refused as stale.

- Resolve flex direction, wrapping, sizing, gaps and alignment from stylesheets and compiled packs.

- Add recoverable native stylesheet diagnostics and `css_tool check --strict`
  with source locations for rejected and browser-only CSS.

- Resolve native viewport-width media queries and responsive equal-width grid
  tracks in parsed sheets and compiled packs while preserving browser export.

- Align the native stylesheet runtime with Kryon size serialization so compiled
  width and height rules survive widget transport.

- Added opt-in native CSS transitions and keyframes for parsed and compiled
  stylesheets, with browser motion declarations preserved in CSS export.

- Added native `color-mix(in srgb, ...)` for two literal color stops with
  browser-compatible percentages and premultiplied alpha.
- Added native `prefers-reduced-motion` queries through `CssEnvironment`,
  including compiled packs and browser-controlled web export.
- Added native CSS gaps and axis padding for `Row` and `Column`, plus font
  weight, font style, signed letter spacing and typed line height for text.
- Added `hwb()` colors, hue angle units and `min-block-size` for horizontal
  layouts. Opacity is clamped after custom properties resolve.
- Updated browser export for Kryon DOM selection and verified style IDs,
  computed styles and widget identity in the production DOM runner.
- Retired the KSS migration tool and legacy system-style loader. Applications
  use CSS sheets and the compiled CSS style packs.
